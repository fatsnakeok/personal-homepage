# 个人网站概要设计文档

## 1. 模块总览

```
personal_homepage/
├── core/                    # 核心框架模块
├── layout/                  # 页面布局模块
├── waterfall/               # 瀑布流展示模块
├── sidebar/                 # 侧边栏模块
├── article/                 # 文章详情模块
├── content/                 # 内容管理模块
├── style/                   # 视觉风格模块
└── deploy/                  # 部署模块
```

## 2. 模块拆解

### 2.1 核心框架模块（core）

负责站点初始化、路由与全局配置。

| 子模块 | 职责 |
|--------|------|
| 站点配置 | 站名、描述、域名、语言等全局参数 |
| 路由管理 | 首页、博客页、简历页、关于页、文章详情页等路由定义与切换 |
| 构建配置 | 静态站点生成器的构建参数（输出目录、插件等） |

### 2.2 页面布局模块（layout）

负责页面整体骨架与响应式适配。

| 子模块 | 职责 |
|--------|------|
| 首页布局 | 全屏背景图、居中内容区（Logo、站名、座右铭、导航按钮） |
| 博客页布局 | 左侧固定侧边栏、右侧文章列表区 |
| 简历页布局 | 简历内容容器、PDF下载按钮 |
| 关于页布局 | 网站介绍与个人简介容器 |
| 页脚 | 版权信息、社交链接 |
| 响应式栅格 | 根据断点切换布局：桌面端侧边栏+主内容，移动端堆叠 |

### 2.3 博客列表模块（blog-list）

负责文章卡片的单列表排列与交互。

| 子模块 | 职责 |
|--------|------|
| 列表布局 | 单列表排列，每行一篇文章 |
| 文章卡片 | 渲染单张卡片：标题、日期、摘要、封面图、标签 |
| 标签筛选 | 按标签 / 分类过滤卡片，高亮当前选中标签 |
| 加载更多 | 滚动触底加载或分页切换 |
| 卡片点击 | 跳转至对应文章详情页 |

### 2.4 侧边栏模块（sidebar）

负责侧边栏内容的展示与交互。

| 子模块 | 职责 |
|--------|------|
| 头像展示 | 个人头像渲染，圆形裁剪 |
| 座右铭展示 | 座右铭文字渲染，装饰元素（引号、分割线） |
| Sticky 定位 | 侧边栏随页面滚动保持可见 |
| 个人简介 | 昵称、一句话介绍 |
| 标签云 | 所有标签的聚合展示，点击跳转筛选 |
| 移动端适配 | 小屏下折叠为抽屉或隐藏 |

### 2.5 文章详情模块（article）

负责单篇文章的完整渲染。

| 子模块 | 职责 |
|--------|------|
| Markdown 渲染 | 将 Markdown 正文转化为 HTML |
| 代码高亮 | 代码块语法着色 |
| 元信息展示 | 发布日期、标签、阅读时长 |
| 返回导航 | 返回博客页按钮或面包屑 |

### 2.6 简历模块（resume）

负责简历内容的展示与交互。

| 子模块 | 职责 |
|--------|------|
| 简历内容渲染 | 个人信息、教育经历、工作经历等模块展示 |
| PDF 下载 | 提供简历 PDF 文件下载链接 |
| 章节折叠 | 移动端支持章节折叠展开 |
| 打印适配 | 优化打印样式，确保简历打印效果 |

### 2.7 内容管理模块（content）

负责文章数据的组织与读取。

| 子模块 | 职责 |
|--------|------|
| 文章目录 | `posts/` 目录下 Markdown 文件的管理 |
| Front Matter 解析 | 提取 title / date / tags / cover / excerpt 等元信息 |
| 文章索引 | 构建时生成文章列表（按日期倒序、按标签分组） |
| 静态资源 | 封面图等资源文件的管理（`assets/images/`） |

### 2.8 视觉风格模块（style）

负责全局样式、主题与设计规范。

| 子模块 | 职责 |
|--------|------|
| 色彩体系 | 主色、辅助色、背景色、文字色等 CSS 变量定义 |
| 字体方案 | 标题、正文、代码字体的引入与声明 |
| 扁平化组件 | 按钮、卡片、标签等基础组件样式（无阴影、纯色、圆角） |
| 间距系统 | 统一的 margin / padding / gap 规范 |
| 响应式断点 | 768px / 1024px 断点的媒体查询定义 |

### 2.9 部署模块（deploy）

负责站点构建与发布流程。

| 子模块 | 职责 |
|--------|------|
| 构建脚本 | `deploy.sh` 一键构建并推送代码 |
| 部署配置 | Gitee Pages 服务配置 |
| 回滚机制 | 重新部署历史版本或 revert 代码 |

## 3. 模块依赖关系

```
core ─────────────────────────────────────┐
  │                                        │
  ├── layout ──┬── waterfall ── content    │
  │            │                           │
  │            ├── sidebar                 │
  │            │                           │
  │            └── article ── content      │
  │                                        │
  ├── style（被所有模块依赖）                │
  │                                        │
  └── deploy（独立于运行时，构建时依赖 core） ◄──┘
```

- **style** 是全局基础模块，所有 UI 模块均依赖其色彩、字体、间距定义
- **content** 是数据层，waterfall 和 article 模块从中读取文章数据
- **layout** 编排 sidebar、waterfall、article 的页面位置
- **deploy** 在构建时依赖 core 的构建配置，运行时无依赖

## 4. 页面与模块映射

| 页面 | 涉及模块 |
|------|----------|
| 首页 | layout + style |
| 博客页 | layout + blog-list + sidebar + style |
| 文章详情页 | layout + article + sidebar + style |
| 简历页 | layout + resume + style |
| 关于页 | layout + style |

## 5. 构建与部署流程

```
posts/*.md ──→ content 解析 ──→ 构建引擎 ──→ 静态 HTML/CSS/JS
                                              │
代码推送 ──→ 构建 ──→ 部署到 Gitee Pages
```
