# 网站样式设计规范

## 1. 设计理念

**自然有机 + 现代简约**的设计风格，追求清新、高对比度、易读的视觉体验。

## 7. 组件样式规范

### 7.1 首页 Hero 组件

- **布局**：全屏背景 + 居中内容
- **背景**：蓝黑渐变 `linear-gradient(135deg, rgba(37, 99, 235, 0.6), rgba(15, 23, 42, 0.7))`
- ** Logo**：圆形，120px，白色边框，脉冲动画
- **标题**：3rem，字体间距 0.1em
- **导航按钮**：毛玻璃效果，圆角胶囊形状
- **移动端**：底部固定导航栏

### 7.2 文章卡片

- **布局**：单列表，每行一篇
- **背景**：白色卡片，圆角 20px
- **边框**：1px solid `#E2E8F0`
- **悬停效果**：
  - 上浮 4px
  - 阴影增强
  - 边框变强调色
- **封面图**：16:9 比例，悬停放大 1.05x
- **标签**：胶囊形状，悬停变主色

### 7.3 侧边栏

- **宽度**：280px
- **定位**：sticky 固定
- **组件**：头像 + 座右铭 + 标签云
- **移动端**：汉堡菜单触发

### 7.4 简历页

- **头部**：彩色渐变条装饰
- **时间轴**：圆点标记，渐变色彩
- **技能卡片**：网格布局，悬停阴影
- **PDF 下载按钮**：固定右上角，胶囊形状

### 7.5 表格样式（关于页技术栈）

- **设计**：卡片式，无边框，柔和阴影
- **表头**：渐变蓝底 + 白字
- **内容行**：
  - 默认：白底 + 深灰字 `#1e293b`
  - 首列：浅灰底 + 深黑字 `#0f172a`
  - 悬停：浅蓝底 `#f0f9ff`
- **圆角**：20px
- **过渡动画**：0.2s ease

## 8. 动效规范

### 8.1 过渡时长

```css
--transition-fast: 150ms ease;
--transition-normal: 300ms ease;
--transition-slow: 500ms ease;
```

### 8.2 悬停效果原则

- 卡片：上浮 + 阴影
- 按钮：背景色变化 + 轻微放大
- 链接：颜色渐变
- 图片：缩放

## 9. 响应式断点

| 断点 | 宽度 | 布局调整 |
|------|------|----------|
| 移动端 | < 768px | 单列，底部导航 |
| 平板端 | 768-1023px | 可折叠侧边栏 |
| 桌面端 | ≥ 1024px | 固定侧边栏 |
