# 关于博客

"空杯成长笔记" 是一个记录个人学习和成长的博客。在这里，我分享技术文章、学习心得和生活感悟。

博客名称来源于"空杯心态"的理念——保持谦虚，放下已有的知识和经验，以初学者的心态去学习和接纳新事物。
